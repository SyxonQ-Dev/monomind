# Coordination Commands

Commands for recording agents in Monomind's agent store. To run agents in parallel, spawn them with Claude Code's Task tool; to run a standing team of roles, use `monomind org run <org>`.

## Commands (invoke as slash commands)

- [agent-spawn](./agent-spawn.md) — record a new agent in the agent store (`monomind agent spawn`; starts no process)
